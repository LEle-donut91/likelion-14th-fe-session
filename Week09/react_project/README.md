# 9주차 개발 일지 - 넷플릭스 로그인 화면 구현

## 주제
넷플릭스 로그인 화면의 전체 틀을 React로 구현한 뒤, 부트스트랩 CSS/JS를 이용해 스타일을 적용하였다.

## 구현 내용
- Netflix 로그인 UI 클론 (Netflix 로고 버튼, 로그인 안내 문구, 이메일 or 비밀번호 입력창, 버튼)
- 부트스트랩 CSS, JS 활용해서 스타일 적용
- 로그인 성공 시, 홈(/home)으로 리디렉션
- 비로그인 사용자가 마이페이지(/my_page) 접근 시, 로그인(/login)으로 강제 이동
- 한국어/English 언어 변경 적용

## 구현 과제
1. 페이지 구현 (홈, 로그인, 마이페이지 등)
2. 그 외 컴포넌트 구현 (헤더, 푸터, 드롭다운 메뉴)
3. 리액트 라우터 사용하여 페이지 이동 처리 (react-router-dom)
4. 비로그인 사용자의 마이페이지 접근 방지 (ProtectedRoute 컴포넌트)
5. 한국어/English 언어 변경 적용 (react-i18next)

## 어려웠던 점 & 해결
- 비로그인 사용자가 마이페이지에 접근이 가능한 상황
    -> ProtectedRoute에서 if-else 구조로 작성해줘야 했는데,
    -> else문을 작성해주지 않아 생긴 버그
    -> else문에서 children을 return하도록 작성해서 해결

- 언어 설정 드롭다운 버튼이 동작하지 않는 상황
    -> 드롭다운 버튼의 onClick에서 드롭다운 메뉴를 보여주는 함수를 호출해야 하는데,
    -> 드롭다운 버튼의 '부모'의 onClick에서 해당 함수롤 호출해서 생긴 버그
    -> '드롭다운 메뉴 보여주는 함수' 호출부를 바꿔서 해결

## 느낀 점
- 다른 사람들이 작성한 코드(넷플릭스 클론 코딩)를 살펴보면서, 내 코드의 부족한 점이 뭔지 파악해봐야겠다.
- 나중에 백엔드 아기사자분들과의 협업을 통해, 실제 API를 연결해보면서 로그인 기능을 완성시키고 싶다.
